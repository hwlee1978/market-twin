## 1. 왜 "출시 전" 해외시장 검증인가

해외진출 실패의 가장 흔한 원인은 기술이 아니라 **시장 미검증**입니다.
"우리 제품은 미국에서 통할 것"이 **검증되지 않은 가정**인 채로 번역·인증·물류·마케팅에
돈을 쓰면, 잘못된 국가·가격·메시지에 자원을 태우게 됩니다.

**숫자로 보는 위험.** 예를 들어 해외 인증 1건 수백만 원, 현지 마케팅 캠페인 수천만 원을
집행한 뒤에야 "이 나라가 아니었다"를 깨닫는 경우가 흔합니다. 반대로 **검증을 먼저** 하면
후보를 1~2개국으로 좁혀 같은 예산을 더 정확한 곳에 집중할 수 있습니다.

전통적 검증(현지 시장조사·바이어 미팅·박람회)은 정확하지만 **비용·시간**이 큽니다.
그래서 순서를 이렇게 잡습니다:

```
[1] 싸고 빠른 가설검증(AI 시뮬)  →  후보국 좁히기
[2] 좁힌 1~2개국만 실사·바이어 컨택  →  실탄 집중
```

> 핵심 사고방식: **"전 세계에 다 팔자"가 아니라 "어디부터, 왜 그곳인지"를 데이터로 답한다.**

## 2. 핵심 개념 3가지

| 개념 | 뜻 | 비유 |
|---|---|---|
| **페르소나(Persona)** | 타깃국 소비자를 대표하는 가상 인물. 인구통계·문화·소비성향 반영 | "그 나라의 다양한 소비자를 모아 둔 표본" |
| **시뮬레이션** | 제품을 다수 페르소나에게 보여주고 구매의향·가격수용·우려를 수집·집계 | "수백 명에게 동시에 설문·인터뷰" |
| **그라운딩(Grounding)** | 정부 통계·문화지표로 AI 추정을 현실에 보정 | "감으로 찍지 않게 실데이터로 눈금 맞추기" |

**왜 600명인가?** 1~2명 인터뷰는 편향이 큽니다. 초기검증 tier는 **서로 다른 3개의
관점(LLM)으로 각 200명씩, 총 600 페르소나**를 돌려 교차검증합니다. 600명의 **분포**를
보면 "다수 반응"과 "소수 강성 반대"를 함께 읽어, 한두 명 의견이나 한 모델의 편향에
휘둘리지 않습니다.

**무엇으로 보정하나(그라운딩 데이터 예).** 국가별 통계(KOSIS), 관세·수출입,
세계은행 거시지표, Hofstede 문화차원(개인주의·불확실성회피 등). 그래서 같은 제품도
나라마다 다른 반응이 나옵니다.

## 4. 5단계 실습 (상세)

### Step 1. 제품 정보 정의
입력 항목: **제품명 / 제품 설명(상세) / 가격 / 카테고리 / (선택) 경쟁사·원산지**

- **제품 설명(상세)**: "기능 나열"이 아니라 **"누구의 어떤 문제를 어떻게 푸는지"** + 특징·타겟·차별점·성분·가격대를 **자유롭게 길게** 작성 (자세할수록 페르소나 반응이 정교해집니다)
  - ❌ "천연 성분 수분 크림"

- **가격**: 현지 판매 예상가(USD 등). 모르면 한국 소비자가 기준으로라도 입력
- **카테고리**: 뷰티 / 식품 / 패션 / 전자 / B2B SaaS 등

## 5. 따라 하는 예제 — 가상의 K-제품으로 처음부터 끝까지

> 아래는 이해를 돕기 위한 **가상 예시**입니다(실제 수치 아님). 본인 제품으로 바꿔 적용하세요.

**제품(Step 1)**
- 제품명: *Hanbom Calm Cream*
- 한 줄 설명: "민감성 피부 2030 여성의 자극 걱정을 줄이는 무향·저자극 수분 크림"
- 핵심 가치: 무향 / 저자극 임상 / 비건
- 가격: USD 24
- 카테고리: 뷰티(스킨케어)

**후보국(Step 2)**: 미국 / 일본 / 베트남 / 독일

**실행(Step 3)** → 잠시 후 결과 대시보드 표시

**결과 예시(Step 4·5)**

| 국가 | 성공 점수 | 가격 수용도 | 신호 |
|---|---|---|---|
| 일본 | 74 | "적정" 다수 | **STRONG** |
| 미국 | 61 | "약간 비쌈" | MODERATE |
| 베트남 | 52 | "비쌈" 다수 | WEAK |
| 독일 | 48 | "적정" 그러나 관심 낮음 | WEAK |

**해석**: top-1 일본이 점수·확신도 모두 앞섬 → "일본부터" 가설이 강화됨.
미국은 가능성 있으나 가격 메시지 보완 필요. 베트남은 가격 저항 → 가격대/용량 재설계 신호.

**다음 액션**: 일본 1순위로 좁혀 ① 일본어 상세페이지 ② 현지 인증·성분 규제 확인
③ 무향·저자극을 전면에 둔 카피 → 그 다음 현지 바이어/플랫폼 컨택.

## 6. 결과를 올바르게 읽는 법 (심화)

**(1) 성공 점수(0~100)**
국가별 종합 적합도 **추정치**입니다. 절대 점수보다 **국가 간 상대 순위**를 보세요.
"몇 점이냐"보다 "어느 나라가 더 유망하냐"가 의사결정에 중요합니다.

**(2) 신호: STRONG / MODERATE / WEAK**
- **STRONG**: 다수 페르소나가 한 국가로 수렴 → 가설이 강하게 지지됨
- **MODERATE**: 어느 정도 쏠리나 경합 → 추가 검증 권장
- **WEAK**: 국가 간 표가 갈림 → "아직 모른다"는 **정직한 신호**(섣부른 확신보다 유용)

**(3) top-1 vs top-3**
top-1만 압도적이면 확신, top-3가 붙어 있으면 신중하게. (여러 나라가 비슷하면
"한 곳을 못 고를 만큼 차별점이 약하다"는 뜻일 수 있음)

**(4) 가격 수용도**
"비쌈/적정/쌈" 분포. "비쌈"이 많으면 → 가격 인하만이 답이 아니라 **가치 전달(왜 그 값인지)**
강화 또는 용량/구성 조정도 선택지입니다.

**(5) 페르소나 반응(정성)**
- **매력 포인트**: 카피·상세페이지의 메인 메시지로 활용
- **우려/반대 사유**: FAQ·인증 표기·리뷰 전략으로 선제 대응

## 7. 흔한 실수 7가지

1. 설명을 "기능 나열"로 적음 → 누구의 어떤 문제인지로 다시 쓰기
2. 후보국을 비슷한 나라로만 채움 → 성격이 다른 나라 섞기
3. 가격을 비워둠 → 가격 수용도 신호를 잃음. 대략값이라도 입력
4. 점수 절대값에 집착 → 상대 순위·신호로 해석
5. WEAK를 실패로 오해 → "더 검증하라"는 유용한 신호로 받아들이기
6. 결과를 정답으로 확정 → 가설 강화/약화의 **보조 자료**로 사용
7. 검증만 하고 액션 없음 → 좁힌 국가로 다음 단계 즉시 설계

## 8. 결과를 얼마나 믿을 수 있나 — 검증·정확도·데이터·규제

시뮬 결과를 제대로 활용하려면 "이게 실제와 얼마나 맞나"를 아는 게 중요합니다. 투명하게 공개합니다.

**① 검증 체계 — 실제 결과와 대조합니다**
- **벤치마크**: 결과가 *알려진* 실제 K-product 사례(불닭·신라면·COSRX·Anua 등 10~15건)로 예측을
  자동 채점해 정확도를 상시 측정합니다.
- **결과 피드백**: 시뮬 후 사용자의 실제 시장 성과를 회수·대조해 **실측 정확도**를 누적합니다.
- **멀티-LLM 교차검증**: Claude·GPT·DeepSeek 3개 모델로 교차 실행 → 한 모델의 편향이 결론을
  결정하지 못하게 하고, **STRONG / MODERATE / WEAK** 신뢰도 신호로 불확실성을 드러냅니다.

**② 정확도 — 정직하게**
- 현재는 **자문(advisory) 등급**입니다. 홀드아웃 기준 종합 점수 평균 약 **55~65점** 수준이며,
  "정확도 90%" 식의 과장을 하지 않습니다. **확신도 신호(STRONG/MOD/WEAK)를 함께 보고** 해석하세요
  — WEAK가 뜨면 "아직 모른다"는 정직한 신호이지 실패가 아닙니다(6장 참조).

**③ 데이터 출처 — 정부 공개데이터 기반**
- KOSIS(통계청)·관세청 UNI-PASS(수출입)·DART(기업공시)·UN Comtrade(무역)·World Bank(거시)·
  Hofstede(문화차원)·KOTRA 등 **공공 API**로 국가·시장을 보정합니다. (입력 시점 기준 역사화)

**④ 국가별 규제**
- 카테고리·국가별 **판매 금지/조건부 허용** 규제 체크를 내장합니다(예: 화장품·식품 성분).
- API 연동 데이터는 실시간, 정적 레퍼런스는 정기 갱신으로 관리합니다.

> 요약: **정부 데이터로 보정 + 여러 AI로 교차검증 + 실제 결과로 정확도 측정.** 그래도 추정치이므로
> **의사결정의 보조 자료**로 쓰는 것이 맞습니다(아래 9장).
